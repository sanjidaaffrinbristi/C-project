# Super Shop Management System 🛒

A desktop-based management application built with **C# (.NET Windows Forms)** and **SQL Server** for handling daily retail superstore operations.

---

## 📌 Project Overview
The **Super Shop Management System** digitizes traditional manual retail record-keeping into a structured database solution. It enables seamless handling of product stock, customer data, employee accounts, and automated point-of-sale (POS) billing.

---

## ✨ Features

### 👨‍💼 Admin Module
- **User Management:** Create, update, and remove employee credentials.
- **Inventory Control:** Add, edit, delete products, manage stock levels, and monitor expiration dates.
- **Dashboard & Search:** Comprehensive oversight of stock levels and employee operations.

### 🧑‍💻 Employee Module
- **POS Billing:** Process customer purchases quickly with auto-calculated subtotals and discounts.
- **Stock Lookup:** Check item availability and pricing in real time.
- **Sales Logging:** Generate transaction receipts with automated customer association.
